Fixed by code, not by this console

Everything on this page affects what the service costs or whether it is safe, and none of it can be changed here. That is deliberate. Each one changes what a paid request actually does, so changing it is a code review and a deploy, not a text box.

It is shown anyway — read-only, with the reason and the file — because a protection an operator cannot see is one they will assume is missing, or worse, assume is a dial they have already checked.

How hard the model is allowed to think

Thinking time is billed at the same rate as the answer and never appears in it. Left at the provider's default, this roughly doubles the entire bill — and because thinking comes out of the same budget as the reply, it can consume the whole allowance and hand somebody a blank answer they have been charged for. Every feature is pinned to the floor.

No web search. No tools. No file search. No attachments. Web search alone bills at $10 per thousand calls — on this service's traffic that would cost roughly sixteen times everything else put together, arriving as a line nobody was watching for. Features that exist but are not shipped

These have an id and an instruction, and are switched off. They are kept rather than deleted so that anyone who reaches them is told the real reason — "this was never built" and "temporarily paused" are completely different facts, and confusing them sends somebody to support over a feature that does not exist.

What is never stored

No prompt text, no document text, no answers. There is no column in the database that could hold them, which is a stronger statement than a policy: it cannot be changed by a setting, only by a migration and a code review.

The single exception is a troubleshooting record that a person opts into per incident. It is scrubbed before it is written and deleted after 30 days by a scheduled job rather than by a promise — see Safety checks for when that job last ran.
