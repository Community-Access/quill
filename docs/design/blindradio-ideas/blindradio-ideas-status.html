BlindRadio ideas for Quill Radio: status and remaining tasks

Started 2026-11-07. This is the running record for the program: what shipped, what is left, and what only Jeff can do. Remove an item when it is done; when everything is done, fold the useful parts into the Radio PRD and user guide and retire this folder.

BlindRadio is by serrebidev, MIT licensed: https://github.com/serrebidev/blindradio. The review that chose these ideas is docs/design/blindradio-review-2026-11-07.md. Every module built from a BlindRadio idea credits it in its docstring.

Files in this folder

  • networks-and-directories.md: curated networks, IPRD, TuneIn, and the directories refused on their terms.
  • song-history-sources.md: What the Station Played.
  • scrobbling-and-recognition.md: scrobbling and AudD.
  • time-shift.md: song marks, adaptive cushion, per-station buffer length (arrives with its branch).
  • dial-tuning.md: the agreed design for dial tuning (not built yet).

Each notes file holds the exact user-guide, PRD and CHANGELOG text, the keys, settings and egress rows added, and what was not verified.
