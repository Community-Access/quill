Tutorials for the BlindRadio ideas

Branch feat/br-tutorials. Six guided lessons in Quill Radio’s Help > Tutorials (Ctrl+Alt+F1) for the features on feat/radio-blindradio-ideas. The features come from BlindRadio by serrebidev (MIT, Copyright (c) 2026 serrebidev); each new lesson module credits the idea in its docstring and its closing paragraph. No BlindRadio text was copied. Dial tuning is not covered; it is being built separately.

What was built

Three new content modules in quill/core/radio/tutorials/, wired into CATALOGUE in __init__.py:

27 minutes and 32 steps added. New totals: 50 lessons, 330 steps, about 292 minutes (was 44 lessons, 298 steps, 265 minutes).

Order: the Networks lesson sits after “Find stations by name, tag and country” and before “Add a station nobody lists”. The five living lessons sit after “Sleeping, waking, and being left alone” and before “Shape the sound”.

Commands named (all real ids, keys from APP_KEYMAPS["radio"]): radio.browse (Ctrl+B), radio.station_playlist (Alt+Shift+H), radio.identify_song (Ctrl+K), radio.previous_song (Alt+Shift+Left), radio.which_song (Alt+Shift+W), radio.next_song (Alt+Shift+Right), radio.save_current_song (Ctrl+Alt+F8), radio.save_previous_song (Ctrl+Alt+F6, with Ctrl+Alt+F7 and Ctrl+Alt+F5 as literals), radio.station_timeshift (Alt+Shift+T), radio.toggle_playing_favorite (Ctrl+Shift+F), radio.play_pause (Ctrl+P). Preferences is written as the literal Ctrl+, as the existing settings lesson does.

Step detection, using only the existing checks: window:Browse Stations when Browse opens, playing when a station starts (Networks, What the Station Played, both time-shift lessons), favorite-added for making a station a favorite. What the Station Played and the Preferences window are modal, not peer windows, so no window check is possible there, as with the other modal surfaces. No new check ids were added.

The scrobbling and AudD lessons need no account: the token boxes are named and left empty, and the last step offers Escape. The scrobbling lesson’s note says what OK with the check box on and no token says (“ListenBrainz is on, but there is no user token yet.”).

Generated: standalone/radio/docs/tutorials.md (by python -m quill.tools.build_tutorials_reference --app radio --write), and its tutorials.html and tutorials.epub, rendered with the same Pandoc invocation and accessible template as standalone/radio/scripts/render_docs.ps1, for that one file only. Pandoc 3.12.1 was used.
