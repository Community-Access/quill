QUILL Tutorials

These are short lessons you do at the keyboard. Each one takes ten to twenty minutes, and walks you through one real task from start to finish. When you want to look something up, the user guide has every detail. The QUILL Cast is an audio course that covers the same ground, if you would rather listen.

QUILLBee's tip: Start with the first one, even if you're in a hurry. It teaches the habits that make every lesson after it easier. Here for the radio or the podcasts? Lessons 9 and 10 are for Quill Radio and QUILL Cast, which are apps of their own, so you can go straight there.

Tutorials for QUILL

  1. Your first hour with QUILL: installing, profiles, the command palette, F1, and habits that make everything else easier.
  2. Own the keyboard: the QUILL key, Quick Nav, changing keys, and the Spoken Echo.
  3. Rescue a scanned PDF: turn a scanned PDF into text you can read and edit, using the Import / Convert Document tool and OCR on your own computer.
  4. From document to published audiobook: choose a voice, use Read Aloud, and use the Audio Studio to narrate a document, combine recordings, fix chapters by ear, and publish a podcast feed.
  5. Start an Accessible Vault: linked notes, backlinks, tags, daily notes and Git sync, starting from an empty folder.
  6. Make a document accessible with GLOW: check a document, fix what it finds, and grade the Word file you export.
  7. Write math without learning a new language: pick a formula from a gallery, type an equation with ordinary keys, explore it by ear, and export it to Word as a real, editable equation.
  8. GitHub inside QUILL: open and save files, work with issues and pull requests, manage a repository, and sort out merge conflicts, all without leaving QUILL.

Tutorials for radio and podcasts

  1. Internet Radio with Quill Radio: play a station, save it as a favorite, learn the keys that work from anywhere, and record a show.
  2. Podcasts with QUILL Cast: follow a podcast, play an episode, pause and skip, and line up what to hear next.

All you need is the app and your screen reader. If you don't use a screen reader, every step works the same way by sight.
