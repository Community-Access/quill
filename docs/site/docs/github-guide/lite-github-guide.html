The GitHub Guide for QUILL and QUILL Lite

This is the book on doing GitHub work with a screen reader in QUILL and QUILL Lite: reading and triaging issues, reviewing pull requests line by line, finding out why a build failed, browsing code, and keeping on top of your notifications. It is a book of its own, beside each editor’s user guide, because there is a lot to say and you may only need part of it.

The same GitHub windows ship in both editors, and so does this book. Where the two differ, a short paragraph starting In QUILL Lite says how.

How to read this book

  • New to it? Read Chapters 1 and 2 in order. They get you signed in and moving. Then go to the chapter for the job in front of you.
  • Reviewing pull requests? Chapter 5.
  • A build failed? Chapter 6, and its section on What Failed.
  • Something went wrong? Chapter 10 has the sentences QUILL says when GitHub refuses, and what to do about each.
  • Looking up a key? Chapter 11 has every one, window by window.
  • Using the GitHub Workbench window? Chapter 12 walks through it, place by place.

Each chapter is a level 3 heading on this page, so pressing 3 in JAWS or NVDA moves from chapter to chapter. Every chapter page starts with its title as a level 1 heading, its main topics are level 2 headings, and at the bottom are links to the chapters either side and back to these contents.

Keys at a glance

  • Opening the workbench. In QUILL, File > Open from Remote > GitHub Items…. In QUILL Lite, File > GitHub Workbench…: Alt+F, then G.
  • Enter goes in, Ctrl+O opens on GitHub, Backspace comes back out.
  • Tab reads the selected row’s details; Shift+Tab returns to the list.
  • Shift+F10 opens the context menu, which holds everything you can do with the selected row.
  • Alt+N and Alt+P move between comments, and between rows in History and Blame.
  • Ctrl+Shift+W says what failed in a workflow run.
  • Ctrl+Shift+L says how much of GitHub’s hourly allowance is left.
  • In a pull request review, Ctrl+R replies to a thread and Ctrl+Shift+R resolves it.
