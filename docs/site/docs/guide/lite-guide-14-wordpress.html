Chapter 14: WordPress

Payment forms use this same WordPress connection. Tools > Forms configures Stripe/PayPal payments and reads provider/webhook readiness; the QAF plugin must implement payment contract version 1. Provider credentials and checkout stay on the site. See Forms for setup and testing.

If you look after a WordPress website, QUILL Lite can write its pages and posts, open the ones already there, and publish your changes. You work in the same editor you use for everything else, with Find, spelling, dictation and all your usual keys. Your site keeps its theme and its look; QUILL Lite works on the words and pictures inside it, and can help you look after the site itself. Nothing reaches your site until you choose to send it. Saving with Ctrl+S only ever saves on your computer.

Turning it on. WordPress is on in the Recommended and Everything profiles, and off in WordPad and Notepad. If you do not see File > WordPress, check WordPress in Tools > Customize Features.

This chapter is the short version. Connecting a site, blocks, pictures and the Media Library, scheduling, checking a page before you publish, comments, menus and running the site are all in the WordPress and Forms manual, which QUILL and QUILL Lite share.

Where everything is

Menu What is there
File > WordPress New, Open, the three saves, Properties, versions, Trash, your sites
Insert Blocks, pictures, links to your own pages, Make a Picture
Format > WordPress Block Settings, Image Size, Mark Language
View WordPress Blocks, Preview Blocks, Play Media Here
Edit > WordPress Next Block, Previous Block, Where Am I
Tools > WordPress Checking, the Media Library, comments, menus, settings, and the More Media and Manage submenus

To get started, choose File > WordPress > Connect a Site…, type your site’s address, and press Get Password with My Browser. Every command is also in the Command Palette (Ctrl+Shift+P): type “WordPress”, or part of a command’s name.

The keys you will use every day

The WordPress commands share one key, Ctrl+Alt+Shift+Grave: the key below Escape, with Ctrl, Alt and Shift held down. Press it and let go, and QUILL Lite says “WordPress keys”. Then press one letter:

Letter Command
O Open Page or Post
P Publish or Update
D Save Draft to Site
W Open by Web Address
M Media Library
S Switch Site
N New Post
G New Page
K Check Before Publishing

Escape after the WordPress key leaves it again. The menus show every command’s letter beside its row, and the manual has the full table. QUILL and QUILL Lite use the same letters, so moving between them costs you nothing.

QUILL Lite finds the grave key by where it sits, the key above Tab, not by what it types. So the WordPress key works on a German, French, Nordic or any other layout, where that key types ^, ² or § rather than a backtick, and you never have to switch to a US layout to reach it.
