Starting QuillVille apps with Windows and WinGet

Choose which supported apps open at sign-in, and whether their windows stay out of the way.

For Windows

These options use the current Windows account. They need no administrator rights. A portable copy does not add a startup entry to the computer it visits.

Start minimized when Windows starts

For an installed app, turn on both its Start with Windows option and its Start minimized when Windows starts option. The app opens without its main window and remains available from the system tray. Starting it normally from the Start menu, a file or another app still opens its window.

  • QUILL: Settings > General. Turn on Start QUILL when Windows starts and Start QUILL minimized when Windows starts. QUILL also enables background mode so the tray icon can reopen the editor.
  • Quill Radio: Preferences (Ctrl+,). Turn on Start Quill Radio with Windows and Start Quill Radio minimized when Windows starts.
  • QUILL Cast: Preferences (Ctrl+,). Turn on Start QUILL Cast with Windows and Start QUILL Cast minimized when Windows starts.
  • Quill Weather: Options. Turn on Start Quill Weather with Windows and Start minimized when Windows starts.
  • Quill Inkwell: Options. Turn on Start Quill Inkwell with Windows and Start minimized when Windows starts.
  • QUILL Transcribe: Options. Turn on Start QUILL Transcribe with Windows and Start minimized when Windows starts.

To show the window at sign-in, leave Start with Windows on and turn off Start minimized when Windows starts. To stop automatic launch, turn off Start with Windows. If Windows hides the app's tray icon, change the notification-area settings so you can bring the app back.

QUILL Transcribe still shows required first-run setup before it can stay minimized. This setting does not start dictation.

WinGet packages

WinGet packages are being prepared for the signed, installed editions. No QuillVille app is currently listed in the WinGet community catalog. Package IDs are still proposals, so there are no install commands to run yet.

After package IDs are approved and their submissions merge, this page will list the exact install and update commands. Packages will use version-specific Stable installers. Portable ZIPs, Beta or Dev builds and the shared runtime will not be separate WinGet packages.
