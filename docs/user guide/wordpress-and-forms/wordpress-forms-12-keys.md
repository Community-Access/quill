# Chapter 12: Every WordPress and Forms key

## What this chapter covers

This chapter lists every key for WordPress and Forms, in QUILL and QUILL
Lite, which use the same keys. It explains the WordPress keys, gives the
whole table of letters, and lists the keys that work inside the WordPress
and Forms windows. Commands without a key are reached from their menus and
from the Command Palette.

## The WordPress keys

The WordPress commands share one starting key: **Ctrl+Alt+Shift+Grave**.
Grave is the key below Escape, also called the backtick key. Hold Ctrl, Alt
and Shift, press Grave, and let go. QUILL says "WordPress keys". Then press
one letter.

The six you will use every day:

- **O** opens a page or post;
- **P** publishes or updates;
- **M** opens the Media Library;
- **S** switches site;
- **W** opens a page by its web address;
- **D** saves a draft to the site.

**How it behaves:**

- **Escape** after the WordPress key leaves it and says "Left WordPress
  keys".
- A letter with no command says so, for example "No WordPress command on
  Q.", and types nothing.
- If you wait more than about four seconds, the WordPress key gives up
  quietly and your next key types as normal.
- The command then speaks for itself, as it does from the menu.
- The menus show each key beside its row, in brackets, such as
  "(Ctrl+Alt+Shift+Grave, O)".
- If you move a WordPress command to another letter in the Keyboard Manager,
  the menus, the key lists and the WordPress keys all follow.

**Why the letters are what they are.** Wherever a File > WordPress row's
underlined letter was free, that is its key, so the menu teaches the key.
Where two rows wanted one letter, the everyday one kept it: Publish kept P,
so New Page went to G; Media Library kept M, so Compare with Site is C;
Switch Site kept S, and Sites, the list you only open now and then, is S
with Shift.

## The QUILL key and the WordPress key

In QUILL, Ctrl+Shift+Grave, the same key without Alt, is the QUILL key,
which starts QUILL's own layer of commands. The two never clash: one has
Alt and one does not. QUILL Lite has no QUILL key, so in QUILL Lite the
WordPress key is the only one of its kind.

## Commands without a key

Every other WordPress command, and every Forms command, has no key of its
own. Each has a written reason in the code: no sensible key is free in both
editors and in every other QUILL app, and these are commands you use now
and then, not every hour. Reach them by:

- **the menus.** File > WordPress opens with Alt+F, then W, in both editors.
- **the Command Palette,** Ctrl+Shift+P, in both editors. Type "WordPress"
  or "form", or part of a command's name, and press Enter.

## Keys you already know

These are the editor's ordinary keys, and they work the same in a WordPress
page or a form:

- **Ctrl+S** saves on this computer, and never sends anything.
- **Ctrl+Z** takes back any change a WordPress or Forms command made to the
  document, as one step.
- **Ctrl+Shift+P** opens the Command Palette.
- **F1** on any control says what it is for.

## Keys inside the windows

- **Enter** runs a list window's main action: Open in the Open window,
  Play or Insert in the Media Library, Read in Responses, Go to It in the
  checking lists.
- **Escape** closes a window without changing anything, and stops the media
  player.
- **Tab** and **Shift+Tab** move between controls; Space checks or unchecks a
  check box.
- In the **Form Outline**, Alt+Shift+Up and Alt+Shift+Down move the question
  you are on, Alt+Shift+Right moves it into the section above, and
  Alt+Shift+Left moves it out.
- In **Fill It In Yourself**, Tab moves from question to question, as on a
  web page.

Payment authoring uses Tools > Forms > Form Payments Setup, Insert Payment
Field and Verify Payment Setup. These occasional commands use their menu
access letters and the Command Palette, with no dedicated default chord.
Responses adds Refresh Payment Status, with its P access key. F1 explains
each focused setup field; Enter accepts and Escape cancels the setup dialog.

## Keys in the other apps

- **QUILL Cast:** Episode > Post This Episode to WordPress.
- **QUILL Studio:** WordPress > Post an Episode to WordPress.
- **Quill Converter:** File > Upload to WordPress.

Each app's own menu shows its key beside the row.
