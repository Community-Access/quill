Chapter 17: WordPress Workbench reference

What this chapter covers

This chapter is for looking things up. It lists every place in the WordPress Workbench’s tree, what you can do to each kind of row, what WordPress’s REST API cannot do, how access and confirmations work, the plugins QUILL supports, and every menu of the window with its keys.

It does not teach. For that, start with Chapter 2, the tour, and each place below names the chapter that shows how to use it.

Opening the Workbench

  • Tools > WordPress > Open WordPress Workbench…, or the WordPress key and then H.
  • The site rows of Tools > WordPress and Tools > WordPress > Manage open it at their own place: Comments, Media Library, Categories and Tags, Menus, Site Check, Site Settings, Users, Application Passwords, Plugins, Themes, Fonts, Synced Patterns, Widgets, Site Map and AI Abilities.
  • File > WordPress > This Post in the Workbench (the WordPress key, then Shift+H) opens the list the post is in, with it selected (Chapter 3).
  • Insert > Picture from the Media Library… opens Media to pick a picture (Chapter 5).

What WordPress’s REST API cannot do

QUILL reaches your site through WordPress’s REST API. It can install, activate, deactivate and delete plugins, but cannot update them or roll them back. It can read themes but not switch or install them. It has no way in to WordPress or translation updates, sign-in sessions, privacy requests, the Customizer, or most of Site Health’s Info tab. The Workbench says so on each row where it matters, before you act, and gives you the way that does work:

  • Open in Dashboard, on plugin, theme, update and Across Sites rows, opens the wp-admin screen that does it.
  • wp-admin for This Place…, on any place in a site, offers the nearest wp-admin screens.
  • Overview > wp-admin Screens lists every wp-admin screen, with how much of it the Workbench does.
  • Anything that asks WordPress.org, such as Check on WordPress.org… or Language Pack Status…, asks you first, naming api.wordpress.org and what is sent.

Access and confirmations

  • Workbench access, for each site (Site > Workbench Access…): Full, the default, allows everything your role does; Organize allows reading and the changes that are easy to undo, such as moderation and the Trash; Read Only allows reading. Safe Mode and View As Role… make every site read only.
  • Your role on the site still decides. A command it does not allow is dimmed, and says which role would.
  • Guards no role lifts: QUILL never removes your own Administrator role or the last Administrator, and warns before you deactivate a plugin QUILL relies on.
  • Every change is previewed, naming the site. QUILL reads the item again first and sends nothing if it changed, then checks what the site kept.
  • A permanent change says it cannot be undone, and Delete Permanently asks you to confirm by name.
  • Change History and Undo WordPress Change are in the Edit menu. Undo is offered wherever putting the old values back truly restores them.

WordPress’s default roles are Subscriber, Contributor, Author, Editor and Administrator. A site can add more. Site > Roles and What They May Do explains the roles the site reports.

Every menu and its keys

These are the keys the Workbench comes with. If you change one in the Keyboard Manager, the menu shows your key instead.

File: New Here… (Ctrl+N), Open on the Site (Shift+Enter), Preview on the Site (Ctrl+Enter), Close Workbench (Alt+F4).

Edit: Undo WordPress Change (Ctrl+Z), Change History… (Ctrl+Shift+H), Copy Link (Ctrl+Shift+C), Filter… (Ctrl+E), Filter Builder… (Ctrl+Shift+F), Show Only Like This… (Ctrl+Alt+O), Hide Like This… (Ctrl+Alt+H), Only Mine (Ctrl+Alt+M), Export List… (Ctrl+Shift+X), Import Posts from a Spreadsheet… (Ctrl+Shift+I), Import a Folder of Documents… (Ctrl+Alt+Shift+I).

View: Refresh (F5), Load More (Ctrl+Shift+L), Load All (Ctrl+Alt+L), Columns… (Ctrl+Alt+C), Group By… (Ctrl+Alt+G), Back (Alt+Left), Forward (Alt+Right), Next Pane (F6), Previous Pane (Shift+F6), Where Am I (Alt+1), Say Selection (Alt+2).

Go: Start Here (Ctrl+9), Needs My Attention (Ctrl+1), Current Site (Ctrl+2), Posts to Site Health (Ctrl+Shift+1 to Ctrl+Shift+9), Across Sites (Ctrl+0), Calendar (Ctrl+3), Watches (Ctrl+5), Practice Site (Ctrl+6), Parent Node (Alt+Up). The nine site places, in order, are Posts, Pages, Media, Comments, Users, Plugins, Appearance, Settings and Site Health.

Item: Properties… (Alt+Enter), Publish or Update… (Ctrl+Shift+P), Approve, or Not Spam (Ctrl+Shift+A), Unapprove (Ctrl+Shift+U), Spam (Ctrl+Shift+S), Reply… (Ctrl+Shift+M), Not Spam, and Allow This Sender (Ctrl+Alt+W), Merge Into… (Ctrl+Shift+G), Convert to Category or Tag… (Ctrl+Shift+K), Approve and Schedule… (Ctrl+Shift+D), Send Back with a Note… (Ctrl+Shift+B), Assign a Reviewer… (Ctrl+Shift+J), Move to Another Day… (Ctrl+Alt+Shift+D), Copy to Site… (Ctrl+Shift+Y), Send Password Reset (Ctrl+Shift+W), Show Its Comments (Ctrl+Alt+Shift+M), Entry Notes… (Ctrl+Alt+N), Star or Unstar Entry (Ctrl+Alt+F), Mark Entry Read or Unread (Ctrl+Alt+U), Resend Notifications… (Ctrl+Alt+I), the Gravity Forms submenu, Move to Trash (Delete), Restore from Trash (Ctrl+Shift+R), Delete Permanently… (Shift+Delete).

Item > Gravity Forms, with no keys of their own: Show Its Feeds, Show Its Results, Test This Form…, Change a Field Type…, Edit Form…, New Gravity Form…, Copy as a QUILL Accessible Form…, Copy QAF Form as a Gravity Form…, Activate or Deactivate Feed…, Rename Feed….

Site: Site Properties… (Alt+Shift+Enter), What Can I Do Here? (Shift+F1), View As Role… (Ctrl+Alt+V), Workbench Access… (Ctrl+Alt+A), Roles and What They May Do (Ctrl+Alt+R), Empty Spam… (Ctrl+Alt+E), Empty Comment Trash… (Ctrl+Alt+Shift+E), Comment Counts (Ctrl+Alt+Shift+C), Your Profile… (Ctrl+Alt+Shift+P), Compare Sites… (Ctrl+Alt+K), Site Sets… (Ctrl+Alt+T), Across Sites Scope… (Ctrl+Alt+Y), Take a Snapshot… (Ctrl+Alt+S), Put Back from a Snapshot… (Ctrl+Alt+Shift+S), Read Site as Document (Ctrl+Alt+D).

Tools: Workbench Options… (Ctrl+Shift+O), REST Console… (Ctrl+Shift+T), Run a Saved Request… (Ctrl+Alt+Q), Saved Requests, Forget a Saved Request… (Ctrl+Alt+Shift+F), Plain-Language Batch… (Ctrl+Alt+B), Practice Site… (Ctrl+Alt+P), and the WXR Files submenu: Export Site as WXR… and Import WXR as Drafts…, reached with Alt+T, W, then E or I.

Window: Switch to Editor (Ctrl+Shift+E). Help: Help for This View (F1), What Is This? (Alt+F1), WordPress Guide (Ctrl+F1), Search Help… (Ctrl+Shift+F1), Workbench Keys (Alt+Shift+F1), Say Last Result Again (F9) and Explain That (Shift+F9).

The commands on a row’s context menu that are not listed here have no key of their own, because they are used now and then. Reach them with the Applications key or Shift+F10.

Some of those, by row:

  • A Site Health or broken link row: Explain (Enter), Fix…, Take Me There and Open in Editor.
  • A plugin: What Depends on It, beside Activate or Deactivate.
  • An explained setting (Permalinks, the Discussion rules, Search engine visibility and plugin settings): Open Its Documentation and Open in Dashboard.
  • A Help and Learning topic: Open (Enter) and Take Me There.
