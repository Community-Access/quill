# Getting help

Support is run by **Community Access**, at **support@community-access.org**. A
real person reads every message, and the reply comes back by email.

The quickest way to write is **Help > Get Help from Support...**
(`Ctrl+Alt+F2`). Every app in the family opens the same form. It asks:

- what kind of message this is,
- a subject,
- what happened,
- and, if you would like an answer, an email address to reply to.

What you expected to happen, and the steps to make it happen again, are
optional. When you can give them, they help more than anything else.

Press Send and **your own mail program opens with the message already written**,
addressed to support. QUILL's name and version and your Windows version are
filled in at the bottom. Nothing goes anywhere until you send it from there, so
you can read it over, add to it, or change your mind.

If this computer has no mail program set up (you only use webmail, say), the app
puts the whole message on your clipboard and tells you the address, so nothing
you typed is lost. You can also simply write to
**support@community-access.org** yourself. There is no form you have to use.
Just say which app you were using and what happened.
