# Trademarks and Naming

This document explains how the QUILL family's names should be used, and how
the family refers to other people's names and marks. It replaces the separate
"Trademark Notices" page, which repeated parts of it.

## The project name

The preferred public name of the project is **QUILL for All**. The full
organisational form is **QUILL for All by Community Access**.

After the full name has been used once in a document or page, the short name
**QUILL** may be used when the context is clear. Avoid bare **QUILL** as the
only project name in public-facing material where it could be confused with
another product.

Preferred one-line description:

> QUILL for All is an open-source, accessibility-focused editor from
> Community Access.

Longer description:

> QUILL for All helps people write, edit, convert, compare, and publish
> documents in a screen-reader-friendly environment.

## The product family

These names identify products of the QUILL for All project. Use them exactly
as written, including their capitals:

- **QUILL for All** (the editor; **QUILL** after first use)
- **QUILL Lite**
- **QUILL Cast**
- **QUILL Studio** (formerly QUILL Audio Studio)
- **QUILL Transcribe**
- **QUILL Social**
- **Quill Radio**
- **Quill Weather**
- **Quill Inkwell**
- **Quill Converter**
- **Quill Media Player**
- **QuillBeacon**
- **QuillVille** (the family as a whole) and the **QuillVille Runtime**
- **Quillins** (QUILL's extensions)

The family's app icons are generated by the project (scripts/build_app_icons.py)
and identify the apps in the same way as their names.

## Contributor guidance

Contributors should:

- Use **QUILL for All** for the editor in user-facing documentation, release
  notes, installers, websites, and announcements, and each app's own name from
  the family list above for that app.
- Avoid creating logos, icons, or taglines that imply affiliation with other
  similarly named products.
- Avoid using third-party names in a way that suggests endorsement,
  sponsorship, or partnership unless such a relationship has been approved in
  writing.
- Preserve the licence, NOTICE and third-party notices files when
  redistributing the project.

## Forks and modified versions

Forks and modified versions should not present themselves as official releases
of QUILL for All or any family app unless the official project maintainers
publish them. Forks should use naming that clearly distinguishes them from the
official Community Access project, for example:

- "Example Editor, based on QUILL for All"
- "Example QUILL fork"
- "Example Accessibility Editor using QUILL for All components"

## Questions

Questions about project naming, branding, or trademark use should be directed
to the Community Access maintainers at support@community-access.org.
