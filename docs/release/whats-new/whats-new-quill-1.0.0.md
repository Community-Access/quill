# What's new in QUILL 1.0

QUILL 1.0 is the first general release. These are the newest parts; the full release notes cover everything else.

## WordPress

- **Write and publish from QUILL.** File > WordPress > Connect a Site fetches the password with your browser. Then New Post, or Open by Web Address.
- **Ctrl+S saves on this computer only.** Save Draft to Site and Publish or Update are separate, Publish checks the page first, and nothing someone else changed is overwritten. Save Draft on a published post asks first.
- **Pictures** ask for alternative text. Scheduling and earlier versions are there too.
- **Blocks, made plain:** Next Block and Where Am I in Edit > WordPress. A block QUILL does not know goes back untouched.
- **Checking:** Check This Page with axe-core, and Check the Whole Site with safe fixes in bulk.
- **Looking after the site:** comments, categories and tags, people, menus and the Media Library.
- **The WordPress Workbench** (Ctrl+Alt+Shift+Grave, then H) runs the whole site, with a preview before every change, Ctrl+Z, Needs My Attention and F1.
- **Moving and copying:** WXR files, Copy to Site, snapshots, and a Practice Site to try it all. Six plugins, from WooCommerce to Gravity Forms.

### Forms

- **File > New Form** writes an accessible form as a short `.qaf` text document, in the language of the QUILL Accessible Forms plugin (formerly BITS Accessible Forms).
- **Tools > Forms > Fill It In Yourself** lets you tab through your own form as a visitor would, before anyone else sees it.
- Check This Form, rules read as sentences in Format > Form Rules, and saving as a web page, Word, large print or braille-ready text. Publish and Responses work with sites running the plugin.
- **Payments:** Stripe and PayPal fields, set up and verified in test mode first. Publishing checks the site is ready, and Responses show each payment. Chapter 18 of the guide walks through it.

## Scribe for Documents

- **Tools > Scribe for Documents** sends a scanned or badly made document to Pneuma Solutions, with your say each time, for Word, tagged PDF, DAISY with audio, MP3 or braille. 100 free pages; chapter 19. Six other apps use it too.

## GitHub

- **From the line you are on:** GitHub > From This Line copies a link to the line, says who changed it, opens its pull request, or starts an issue from your selection.
- **The GitHub Workbench:** one window for all of GitHub. Alt+Enter changes anything, Ctrl+Z undoes it, and Dry Run tries a command first. Help > Practice on GitHub gives you a repository to learn on.

## Say or Type a Command

- **F11:** type what you want in your own words, such as "make this bold". It does only what this window can, free and offline. If you say yes, Jev or your own AI helps when it is not sure. **What Can I Say Here? (Ctrl+Alt+Shift+F1)** lists the rest.

## AI and code

- **Choose Your AI (Ctrl+4)** lists QUILL's free AI, your ChatGPT plan, GitHub Copilot, Codex and your own key. **Which AI Am I Using (Ctrl+8)** says where your words go.
- **Do a Document Task (Ctrl+3)** gives Copilot or Codex a job with several steps, and asks before each change.
- **Project tasks,** in the Developer profile: open a folder of code, press Ctrl+3, and review every change and every command before it happens. Undo Last Agent Turn puts everything back.

## Writing

- **Ctrl+Enter** inserts a page break, as in Word. Word documents keep their page breaks now.
- **The Command Palette (Ctrl+Shift+P)** finds every menu item, recent files and open documents included.
- **Tables** you can read cell by cell, and Insert Table (Ctrl+Alt+T). **Find in Open Documents** (Ctrl+Shift+F10).
