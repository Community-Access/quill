# What's new in QUILL Lite 2.0

QUILL Lite 2.0 is about words, websites and never missing what happened. Your settings, recent files and recovered work come with you.

## Before you update

- **Using the portable QUILL Lite 1.1.2? Update by hand this once.** Its Install and restart can delete its data folder. Close QUILL Lite, copy the data folder next to QuillLite.exe somewhere safe, unzip the new zip into a new folder, and copy your data folder into it.
- **Keys that moved:** Keyboard Manager Ctrl+Alt+Shift+Space, Snippets Ctrl+Alt+Shift+Home, Remove Quote Marks Alt+Shift+. (period), Collect Selection Alt+Shift+C, Trim Trailing Spaces Ctrl+Alt+R.

## WordPress

- **Write and publish from QUILL Lite.** File > WordPress > Connect a Site: approve QUILL in your browser. Then New Post, or Open by Web Address.
- **Ctrl+S only saves on this computer.** Publish checks the page first, and nothing someone else changed is overwritten. Pictures ask for alternative text.
- **Blocks read as plain text.** Check This Page checks a page the way a visitor meets it.
- **Looking after the site:** comments, categories and tags, people, menus and the Media Library.
- **The WordPress Workbench** runs the whole site, with a preview before every change and Ctrl+Z. It moves content with WXR files and Copy to Site, and knows six plugins.
- **Ctrl+Alt+Shift+Grave, then a letter:** O Open, P Publish, D Save Draft, M Media Library, H the Workbench.

### Forms

- **File > New Form** writes an accessible form as plain text. Form Rules reads each rule as a sentence, and **Tools > Forms** checks it, lets you fill it in yourself, publishes it with the QUILL Accessible Forms plugin, reads the responses, or saves it in large print or braille.
- **Payments:** Stripe and PayPal fields, in test mode first; chapter 16 walks you through it.

## Say it, or find it

- **Say or Type a Command (F11):** say what you want in your own words. Free and offline; Jev or your own AI helps if you say yes.
- **The Developer profile:** open a project folder and Ctrl+3 asks an AI to work on it. You review every change and allow every command first, and Undo Last Agent Turn puts every file back.
- **The Command Palette (Ctrl+Shift+P)** is in Tools and in every profile, and reaches every command and menu item.

## GitHub

- **From the line you are on:** the GitHub menu copies a link to the line, says who changed it, opens its pull request, or starts an issue from your selection.
- **The Workbench:** Export List (Ctrl+Shift+X) saves any list as Excel, CSV or Markdown. Import Issues (Ctrl+Alt+I) and New Issues from Lines (Ctrl+Alt+L) make many issues at once, after a preview.

## Choose Your AI

- **Choose Your AI (Ctrl+4)**: QUILL's free AI, your ChatGPT plan, GitHub Copilot, Codex or your own key. **Which AI Am I Using (Ctrl+8)** says which is in use; **Do a Document Task (Ctrl+3)** gives Copilot or Codex a job to do.

## Words, tables and documents

- **Thesaurus (Shift+F7)**, **Look Up Word (Alt+F10)** without the internet, and an AI dictionary.
- **Word documents open and save as Word**, and **Ctrl+Enter** is a page break. PDFs open as text, with OCR on this computer.
- **Insert > Table (Ctrl+Alt+T)** in any document; the arrows read a table cell by cell.
- **Find in Open Documents (Ctrl+Alt+Shift+F8)**, Search in Files and Replace Across Files.
- **Spell check skips** web addresses, file names and code.

## Knowing what happened

- **Activity (Shift+F9)** lists everything QUILL Lite told you; **F9** says the last thing again. If NVDA or JAWS stops, unsaved work is saved first.
