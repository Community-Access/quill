# What's new in QUILL Lite 2.0

QUILL Lite 2.0 is about words, and about never missing what happened. Your settings, recent files and recovered work come with you.

## Before you update

- **Using the portable QUILL Lite 1.1.2? Update by hand this once.** In that copy, Install and restart can delete its data folder. Close QUILL Lite, copy the data folder next to QuillLite.exe somewhere safe, unzip the new portable zip into a new folder, and copy your data folder into it. An installed copy is not affected.
- **Keys that moved:** Keyboard Manager is now Ctrl+Alt+Shift+Space, Snippets Ctrl+Alt+Shift+Home, Remove Quote Marks Alt+Shift+. (period), Collect Selection Alt+Shift+C, and Trim Trailing Spaces Ctrl+Alt+R.

## Finding the right word

- **Thesaurus (Shift+F7)** finds the meaning of the word you are on, and the word you choose goes into your sentence in the right form.
- **Look Up Word (Alt+F10)** is a dictionary that works without the internet. The AI dictionary reads your word in its own sentence and tells you whether it is the right one.

## Word documents, PDFs and other files

- **Word documents open as rich text, and Ctrl+S saves a real Word document**, with headings, lists, tables and links. If a save would lose something, QUILL Lite names it first.
- **PDFs open as text**, page by page, in the installed and portable copies. A scanned page is read with Windows OCR on this computer; nothing is uploaded.
- **Excel, PowerPoint and OpenDocument files open as readable text**, each sheet and slide named.

## Tables

- **Insert > Table (Ctrl+Alt+T)** makes a table in any document. In rich text it is a real table, which your screen reader, Word and WordPad see as one.
- **The arrows read a table cell by cell**: Up and Down go to the cell above and below and say it. Tab and Shift+Tab move cell to cell, and Tab in the last cell adds a row.
- **Navigate > Table** has the table keys, such as Ctrl+Alt+Right for the next cell, and adds or deletes rows and columns.

## Writing and editing

- **Find in Open Documents (Ctrl+Alt+Shift+F8)** searches and replaces across every document you have open. Search in Files (Ctrl+Alt+Shift+F) and Replace Across Files (Ctrl+Shift+R) work on a whole folder.
- **Inline notes (Alt+Shift+I)** leave a comment on a line; Alt+Shift+Enter lists them.
- **Recent Documents (Alt+Shift+0)**, with pinning. **Toggle Task Done (Ctrl+Alt+Enter)**. **Export as HTML (Ctrl+Alt+Shift+End)**. **AutoCorrect**, off until you turn it on.
- **The clipboard collector (Alt+Shift+S)** gathers everything you copy, in any program, into one document.

## Spell check and display

- **Spell check reads only what you wrote.** Web addresses, email addresses, file paths and file names are skipped everywhere; Markdown skips code and link addresses; web pages are read for their text; and in code only strings and comments are checked. The file's extension picks the rule.
- **Recovery quotes how each document begins**, and text stays sharp at 150 and 200 percent display scaling.

## Knowing what happened

- **Activity (Shift+F9)** lists everything QUILL Lite has told you, and **F9** says the last important thing again.
- **If NVDA or JAWS stops, your unsaved work is saved first.** Braille no longer flickers during a burst of messages.

## Dictation and AI

- **Dictation profiles** for email, documents, Markdown, chat and code, Spanish dictation, and optional speech models that make fewer mistakes.
- **The AI asks before switching** to QUILL's free AI, tries again when it is busy, and reads answers without Markdown symbols. Prompt Library is on Ctrl+7.

## More

**Help > What's New** (Alt+H, W) opens the full changelog, and with every document closed the menu bar still has File, Tools and Help.
