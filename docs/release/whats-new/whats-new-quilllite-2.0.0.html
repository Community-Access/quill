What’s new in QUILL Lite 2.0

QUILL Lite 2.0 is about words, websites and never missing what happened. Your settings, recent files and recovered work come with you.

Before you update

  • Using the portable QUILL Lite 1.1.2? Update by hand this once. Its Install and restart can delete its data folder. Close QUILL Lite, copy the data folder next to QuillLite.exe somewhere safe, unzip the new zip into a new folder, and copy your data folder into it.
  • Keys that moved: Keyboard Manager Ctrl+Alt+Shift+Space, Snippets Ctrl+Alt+Shift+Home, Remove Quote Marks Alt+Shift+. (period), Collect Selection Alt+Shift+C, Trim Trailing Spaces Ctrl+Alt+R.

WordPress

Stripe and PayPal form setup

  • The same Forms commands as QUILL insert payment fields, configure Stripe and/or PayPal, and read site readiness. New settings start in test mode.

  • Paid-form publication checks provider/webhook readiness and mode. Test on Site refuses a published live-payment checkout. Responses include payment status and exports, with Refresh Payment Status after confirming the site.

  • Checkout needs the QAF plugin’s payment support; chapter 16 walks you through it.

  • File > WordPress writes, opens and publishes your sites’ pages and posts. Connect by approving QUILL in your browser, or paste an application password. Ctrl+S only saves on this computer; Publish checks the page first. Scheduling, earlier versions and working offline are there too.

  • Blocks read as plain text, and Next Block and Where Am I say where you are. Tools > WordPress checks a page the way a visitor meets it and looks after media, comments, menus and users.

  • Ctrl+Alt+Shift+Grave, then a letter: O Open, P Publish, D Save Draft, M Media Library.

Forms

  • File > New Form writes an accessible form as plain text. Form Rules reads each rule as a sentence, and Tools > Forms checks it, lets you fill it in yourself in each of its languages, publishes it with the QUILL Accessible Forms plugin, reads the responses, or saves it in large print or braille.

Say it, or find it

  • Say or Type a Command (F11): say what you want in your own words. Free and offline; Jev or your own AI helps if you say yes.
  • The Developer profile: open a project folder and Ctrl+3 asks an AI to work on it. You review every change and allow every command first, and Undo Last Agent Turn puts every file back.
  • The Command Palette (Ctrl+Shift+P) is in Tools and in every profile, and reaches every command and menu item.

Choose Your AI

  • Choose Your AI (Ctrl+4): QUILL’s free AI, your ChatGPT plan, GitHub Copilot, Codex or your own key. Which AI Am I Using (Ctrl+8) says which is in use, and Do a Document Task (Ctrl+3) gives Copilot or Codex a job with several steps.

Words, tables and documents

  • Thesaurus (Shift+F7), Look Up Word (Alt+F10) without the internet, and an AI dictionary.
  • Word documents open and save as Word, and Ctrl+Enter is a page break. PDFs open as text, with OCR on this computer.
  • Insert > Table (Ctrl+Alt+T) in any document; the arrows read a table cell by cell.
  • Find in Open Documents (Ctrl+Alt+Shift+F8), Search in Files and Replace Across Files.
  • Spell check reads only what you wrote, skipping web addresses, file names and code.

Knowing what happened

  • Activity (Shift+F9) lists everything QUILL Lite told you; F9 says the last thing again. If NVDA or JAWS stops, unsaved work is saved first.
