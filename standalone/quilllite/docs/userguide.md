# QUILL Lite User Guide

## GitHub workbench

Choose **Tools > GitHub Workbench...** (**Ctrl+Alt+Shift+F6**) to use the same
GitHub Items viewer as QUILL. After network consent, enter a repository or use
the one inferred from the current document's checkout. Select a PR and choose
**Review...**. Arrow through the expandable PR, files, conversations, and
checks. Tab into the selected details; Shift+Tab returns. Ctrl+R replies to a
selected review thread, and Shift+F10 opens its context menu. The
[GitHub tutorial](../../../docs/tutorials/08-github-inside-quill.md) explains
the complete interaction model.

*For QUILL Lite 2.0.0 (build 1), the beta for testers, October 2026. 2.0.0
was prepared as 1.2.0 on October 3, 2026, renumbered on October 31, and is
not yet published; the last published version is 1.1.2.*

This is the guide to QUILL Lite, the text editor for people who use a screen
reader. You can open any text file, change it, and save it back exactly the
way it came in, and every chapter here is about doing one part of that well.

Each chapter is a page of its own. This page is the contents: every chapter,
two sentences on what it covers, and links to its main topics, so you can go
straight to the part you need.

## How to use this guide

You do not have to read any of this before you start. Open QUILL Lite, type,
and press **Ctrl+S**. When you want more,
[Chapter 1: Your first minutes](guide/lite-guide-01-your-first-minutes.html)
is the place to begin, and after that you can read in order or jump to the
chapter you need.

- On this page, each chapter is a level 3 heading. Press 3 in JAWS or NVDA to
  move from chapter to chapter, and Tab or the down arrow to hear its topics.
- Every chapter page starts with the chapter's title as a level 1 heading. Its
  main topics are level 2 headings, and their parts are level 3 and below.
- At the bottom of every chapter are links to the chapter before it, the one
  after it, and back to these contents.
- The QUILL Lite User Guide shortcut in the Start menu opens this page. Inside
  the app, **F1** answers in every window, and **Ctrl+F1** lists every key.
- If you would rather read the whole guide as one book, `userguide.epub`, in
  the docs folder beside QUILL Lite, has every chapter in it, in order.
