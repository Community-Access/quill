# Chapter 10: QUILL Lite

## What this chapter covers

Everything in this manual works in QUILL Lite as it does in QUILL. This
short chapter says why, and lists the few places where the two editors
differ: how you turn the features on, a handful of menu access letters, and
the QUILL key. If you use both editors, read this once and you can move
between them without thinking about it.

## One set of commands, two editors

WordPress and Forms are not two features that happen to look alike. They are
one piece of shared code that both editors reach. The menus in both are
built from the same tables, every command runs the same handler, and a test
checks that neither editor has a second copy of anything. So:

- every command is in the same menu, with the same name, in both editors;
- every window, field and button is the same, and says the same things;
- the WordPress keys are the same letters (Chapter 12);
- a draft that QUILL Cast or QUILL Studio leaves for you is in Open Local
  Draft in either editor.

## Turning the features on

| | QUILL | QUILL Lite |
|---|---|---|
| Where | Profiles and Features... | Tools > Customize Features |
| WordPress on in | every profile except Essential | Recommended, Everything, Developer |
| Forms on in | every profile except Essential | Recommended, Everything, Developer |
| Off in | Essential | WordPad, Notepad |

In QUILL Lite, WordPress and Forms are two of the 24 areas Customize
Features lists. WordPad and Notepad leave them off on purpose, because
neither of those programs ever published to a website or made a form, and
those profiles promise to be exactly what they are named after. Check the
area in Customize Features to turn it on without changing profile.

## Menu access letters

The commands sit in the same menus, but QUILL Lite's menus are fuller, so a
few rows have different underlined letters, or none:

- **File > WordPress** opens with Alt+F, then W, in both editors.
- **Edit > WordPress**, **Tools > WordPress** and **Tools > Forms** have no
  access letter in QUILL Lite's Edit and Tools menus, because every letter
  of their names is already taken there. Arrow to them, or use the Command
  Palette.
- **New Form** is M in QUILL Lite's File menu, and **Form Rules** is M in
  its Format menu.

Rows that lack a letter are still reached by arrowing through the menu, by
their WordPress key where they have one, and by the Command Palette.

## The Command Palette

Ctrl+Shift+P opens the Command Palette in both editors, and it is in the
Tools menu in both. It lists every WordPress and Forms command, with its key
beside its name where it has one. Type "WordPress" or "form", or part of a
command's name, and press Enter. QUILL Lite keeps the palette in every
profile, even Notepad, because it is how a command is found.

## The WordPress keys and the QUILL key

The WordPress keys start with Ctrl+Alt+Shift+Grave in both editors (Chapter
12). In QUILL, the same key without Alt is the QUILL key, which starts
QUILL's own layer of commands. QUILL Lite has no QUILL key, so in QUILL Lite
the WordPress keys are the only two-press keys.

## Old Publish connections

Older versions of QUILL had a Publish submenu, and QUILL brings its saved
connections into WordPress the first time it loads. QUILL Lite never had
Publish, so there is nothing to bring in: connect your sites in QUILL Lite
with Connect a Site.
