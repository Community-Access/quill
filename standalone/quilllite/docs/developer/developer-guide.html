QUILL for Developers

This is the developer’s manual for QUILL and QUILL Lite. It covers coding with an AI in your own project folder, which both editors share from the same code, and the code editing features of the editor itself. It is a book of its own, beside each editor’s user guide, because nobody who does not write code needs any of it.

Everything here lives behind one choice, the Developer profile. Until you choose it, none of it appears: not in the menus, not in the Command Palette, not in the tutorials.

How to read this manual

  • New to project tasks? Read Chapters 1, 2 and 3, in that order. They take you from turning the tools on to a finished, undone task in a practice folder. Then dip into the rest as you need it.
  • Want to know what the AI may and may not do? Chapters 2 and 5 are the whole answer: the project boundary, and the permissions.
  • Learning to code? Read Chapter 9, on coach mode, after Chapter 3.
  • Using QUILL Lite? Everything applies; Chapter 12 has the few differences, and Chapter 1 the one extra check box.
  • Looking something up? Chapter 14 has every key and Chapter 15 every window, control by control.
  • Something went wrong? Chapter 13 has the sentences QUILL says, and what to do about each.

Every chapter starts with a short “what this chapter covers” and ends with links to the chapters either side and back to these contents. Headings are real headings, so your screen reader’s heading keys move through each chapter. Throughout, “cli-tool” stands for your own project folder’s name, which QUILL says in its place.

Keys at a glance

  • Ctrl+3 opens Do a Project Task while a project is open, and Do a Document Task when none is. One key, in both editors.
  • Ctrl+4 opens Choose Your AI, where you pick the engine.
  • In the task window: Alt+I Instruction, Alt+P the plan, Alt+H the changes, Alt+O the last command’s output, Alt+R the transcript, Alt+U Undo Last Turn, Alt+X Explain Last Turn, Alt+A Coach mode, Alt+T Stop.
  • In QUILL, the QUILL key (Ctrl+Shift+Grave, Grave being the key below Escape) then K stops the agent from any window, and then U undoes the last agent turn. In QUILL Lite these are Edit > Agent Work.
  • In Review Changes: Space takes or leaves a file, Enter moves to its changes, Alt+A and Alt+R accept and reject, Alt+N and Alt+P move, and Enter on Apply Accepted Changes writes what you accepted. Escape writes nothing.
  • In Run This Command?: Enter allows once, Escape does not allow.
  • Ctrl+Shift+P, the Command Palette, finds every developer command by name.
  • F1 on any control says what it is for.

Chapter 14 has every key.

About this manual

This manual describes the Developer profile as it ships in the current QUILL and QUILL Lite. The plan of record for the coding features is docs/design/code.md in QUILL’s source. If something here does not match what you hear, tell us through Help > Get Help from Support.
