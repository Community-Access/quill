Chapter 11: Keyboard reference

What this chapter covers

Every key the workbench answers to, one window at a time. Keys marked as access keys are the underlined letters of a control, pressed with Alt; they work while that window has focus. Keys that open the windows themselves are in Chapter 1. QUILL’s GitHub menu commands have no keys out of the box, and you can give them some in the Keymap Editor.

Throughout, Shift+F10 or the Applications key opens the context menu of whatever has focus, and Escape closes the window you are in.

GitHub Items

Anywhere in the window

Key What it does
Ctrl+R Reload the current view
Ctrl+O Open the selected row on GitHub, in your browser
Ctrl+G Go to an issue or pull request by number
Ctrl+D Add the selected row to your favorites
Ctrl+F Move to the Search box
Ctrl+Shift+F Move to the Quick filter
Alt+N, Alt+P Next or previous comment in Details
Ctrl+Shift+B Compare two branches, in Branches
Ctrl+Shift+W What Failed, in Workflow Runs
Ctrl+Shift+L GitHub’s remaining allowance

Escape in the Quick filter clears it, when it has text. Otherwise Escape closes GitHub Items.
