Quill Inkwell changelog

Unreleased

  • Speech providers in Dictate Anywhere (2026-10-16). Dictation Settings has the editors’ Speech Providers… button (Alt+V), so Dictate Anywhere can use a speech company you already have an account with. Keys go to Windows Credential Manager, and you are asked before anything is sent.

  • Every release build checks its version against what is published (2026-10-15). The shared QuillVille runtime carries every app’s version number, so a build of one app could make another report a version nobody can download yet, and Check for Updates would then never offer the real one. Quill Inkwell’s release builds now run the same check Quill Radio, QUILL Lite, QUILL Cast and Quill Weather already did, and a build of every app at once checks them all again instead of stopping at an app it did not know.

  • The command word in Dictate Anywhere (2026-10-15). Say QUILL before a command, “QUILL scratch that”, and whatever follows QUILL is never typed; if it is not a command you hear “Not a command”, and “QUILL type that” types it. “QUILL command mode” takes commands without the word until “dictation mode” or eight seconds with none. The word, strict mode and the seconds are in More Dictation Settings (Alt+C, Alt+E, Alt+D). Two new sounds play when QUILL hears the command word and when command mode ends.

  • QUILL Lite’s words in Dictate Anywhere (2026-10-15). Dictate Anywhere uses QUILL’s My Words and Phrases list, as before. QUILL Lite can now share that list (Use the shared word list, in its My Words and Phrases), so the names you teach QUILL Lite come out right here too. QUILL, QUILL Lite and QUILL Transcribe can also import and export the list.

  • Dictate Anywhere stays in the field you started in (2026-10-15). If the focus moves while you dictate, Inkwell pauses and holds your words instead of typing them somewhere else, as QUILL Transcribe does. Dictation > Resume (Ctrl+R), Resume in This Field (Ctrl+Shift+R) and Discard Held Words (Ctrl+Shift+D), also in the tray menu while paused.

  • Programs dictation never types into (2026-10-15). A list you keep, in More Dictation Settings (Alt+N), that starts with the common password managers and the Windows sign-in prompts. Dictation refuses a listed program by name and types nothing.

  • Where Quill Inkwell’s own sounds play, and Alt+Shift+M to turn them off. Options > Preferences > App Sounds Play On… offers System default, None (no sounds), or any sound card or headset by name. After a change one sound plays on the new card, so you hear where it went. If that card is unplugged the sounds play on the system default until it is back, and Quill Inkwell says so once. Alt+Shift+M turns Quill Inkwell’s sounds off and back on where they were, and Options > App Sounds shows a check mark while they are on. Each QUILL app keeps its own choice; “Share these choices with my other Quill apps” keeps them in step. Your screen reader is never moved. Asked for on QUILLVille by Rick Lewis.

  • Dictate Anywhere: one microphone, and your library by voice (2026-10-13). Inkwell takes the family’s one microphone lock while it listens, so it never dictates at the same time as QUILL, QUILL Lite or QUILL Transcribe, and it says which one is when it cannot start. “insert snippet”, “insert abbreviation” and “paste clip” now work in other programs, typed as one phrase that “scratch that” takes back whole (blanks are typed as [name], and the cursor stays at the end). Its Dictation Commands list shows only what works in other programs.

  • Two downloads, nothing else (2026-10-11). Quill Inkwell now comes as the installer and the portable zip. The small Lite installer and the Companion zip are gone. If you used the Lite installer, take the installer; if you used the Companion zip, take the portable zip. Check for Updates already offers the right one.

  • Dictate Anywhere (2026-10-05). Inkwell now hosts dictation into other programs, with the editors’ shared controller, engines, My Words and Phrases (dictation.md in the shared data folder) and commands (quill/apps/inkwell_dictation.py, quill/core/windows_dictation/anywhere.py, quill/ui/windows_dictation_external.py). File > Dictate Anywhere Key… (Ctrl+Alt+Shift+D) chooses the system-wide key, none by default, with the same picker and refusals as the other keys. A new Dictation menu has Dictate Anywhere (Ctrl+D, a check item) and Dictation Settings… (Ctrl+Alt+D), the editors’ own window over Inkwell’s stored copy. Each phrase is typed at the cursor of the program in front; “scratch that” sends backspaces only while the same window keeps the focus. Commands that need to read the other program’s text (select, go to, correct, clips, snippets) are answered “That works in QUILL’s own documents…”. Refused with a sentence: password fields, programs running as administrator when Inkwell is not, QUILL’s own windows (Ctrl+F11 there) and Inkwell’s own window. The read-back defaults to a tone, since the screen reader echoes typing. An editor’s Dictate in Other Programs… hands its settings over once (dictate-anywhere.json) and starts Inkwell, opening the key chooser if no key is set. Off in Safe Mode.

  • No show and hide key until you choose one (2026-10-05). The app registered Ctrl+Alt+Shift+I system-wide, and other QuillVille apps use that key for menu commands, so while this app ran theirs never fired. It now has no key by default; File > Show and Hide Key… (Ctrl+Alt+Shift+H) lets you type one, or leave it empty for none, and refuses a key any QuillVille app uses as a command or as its own show and hide key, in one sentence naming the app. Somebody who had the old key is moved to none and told once, at the next launch; a key somebody chose is kept (quill/core/family_chords.py, quill/core/show_hide_keys.py, quill/ui/show_hide_key_picker.py).

  • No Quick Insert or Expand Word key until you choose one (2026-10-05). Ctrl+Alt+Shift+K (Quick Insert) and Ctrl+Alt+Shift+X (expand the word just typed) were registered system-wide too, and both are commands elsewhere in the family – X is Quill Radio’s Export My Setup – so they went the same way. File > Quick Insert Key… (Ctrl+Alt+Shift+K) and File > Expand Word Key… (Ctrl+Alt+Shift+E) use the same picker and the same refusals, and also refuse a key Inkwell already uses for one of its other two. Somebody still on the old keys is moved to none and told once in one sentence; a key somebody chose is kept (quill/apps/inkwell_keys.py, InkwellSettings.take_system_keys).

1.0.0 – 2026-08-11

First release. Abbreviation expansion in every Windows application, sharing one library with QUILL.

Added

  • An application icon of its own. This was the single hard blocker on cutting the 1.0.0 build, which is why it is recorded here rather than as a fix after the fact. The icon the app was scaffolded with was a byte-identical copy of Quill Weather’s – which was itself a copy of Quill Radio’s – so a listener with more than one QuillVille app installed would have seen the same face for several different products in the taskbar, in Alt+Tab and in the tray. For a tray-resident app like Inkwell, the tray is where it lives its whole life.

    Inkwell’s icon is a gold nib dipped into a white inkwell, on a terracotta tile: the app is named for the well, and the pot is a silhouette nothing else in the family has. It shares the family’s rounded tile shape and gold accent, and differs from every sibling in picture and in colour. Two alternatives were drawn and rejected for failing at 16x16, which is the size that actually matters – expanding text lines blurred to a grey block, and a bare fountain nib read as a flame.

  • System-wide expansion. A low-level keyboard hook recognises an abbreviation as you finish typing it and replaces it in whatever application has focus. Expansions are typed as synthesised keystrokes and never touch the clipboard.

  • One shared library. Inkwell and QUILL read and write the same abbreviations.json. An abbreviation added in either app works in both, with no import or sync; the file is re-read whenever it changes on disk.

  • Per-abbreviation settings. Each entry carries its own category, trigger mode (a space or punctuation, a space only, punctuation only, or never), speech mode, sound override, trailing-space behaviour, and case sensitivity. Schema version 2, backward and forward compatible.

  • Quick Insert. A type-to-filter picker over every enabled abbreviation, ordered by how often each is used, reachable from the window (Ctrl+K) or from anywhere (Ctrl+Alt+Shift+K). The only way to reach an entry whose trigger mode is Never.

  • New from Clipboard. Ctrl+Shift+N turns whatever is on the clipboard into a new abbreviation, pre-filled.

  • Fill-in fields. ${field:Label} and ${field:Label=default} make an expansion ask before it finishes; a label used twice is asked once and filled everywhere. The form is the same one QUILL’s editor uses, so a template behaves identically in both.

  • Categories with a filter in the manager, and a category column in both lists.

  • Variables in expansions: ${date}, ${time}, ${datetime}, ${day}, ${month}, ${year}, ${username}, ${clipboard}, ${cursor}.

  • Case preservation. Btw capitalises and BTW shouts, for entries that are not case sensitive.

  • Exclusions. Password managers, the Windows sign-in and lock surfaces, the credential prompt, and the UAC dialog are permanently excluded, plus any applications the user adds.

  • Paste fallback for the few applications that drop synthetic keystrokes; the previous clipboard contents are always restored.

  • Tray residence, start-with-Windows, start-minimized, and a close button that keeps expansion running.

  • Safe Mode support. QUILL_SAFE_MODE=1 prevents the keyboard hook from being installed at all.

Working everywhere you can type

  • Expands only where text is accepted. Before replacing anything, Inkwell checks that the focused element takes text, so backspaces never land in a list doing type-ahead or a page where Backspace means “go back”. Where it cannot tell, it goes ahead – a missed expansion is the more annoying failure.
  • AltGr characters no longer break expansion. Windows reports AltGr as Ctrl+Alt, and treating that as a command wiped the buffer mid-word on every layout that uses it – German, Polish, Spanish, Portuguese, the Nordic layouts. AltGr is now recognised as typing.
  • Backspace immediately after an expansion takes it back, restoring the abbreviation. The offer lasts a few seconds and only in the window where the expansion happened.
  • Expand on demand with Ctrl+Alt+Shift+X (or the Abbreviations menu): expands the word before the cursor without waiting for a space or punctuation, so it works mid-word, at the end of a line, and for entries set never to expand on their own.
  • Quick Insert from anywhere with Ctrl+Alt+Shift+K.
  • Per-application delivery. The clipboard-paste route can be turned on for one stubborn program (paste_processes in inkwell.json) instead of globally, so no other application has its clipboard borrowed.
  • The hook repairs itself. Windows silently removes a keyboard hook that responds too slowly; Inkwell re-installs its own every few minutes so expansion cannot quietly die for the rest of a session.
  • One expander per window. QUILL’s editor expands from the document itself, so Inkwell stays out of it rather than expanding the same word a second time. QUILL marks its own window; the marker identifies the actual window, so a development run and a renamed build are covered alike.
  • Elevated windows are explained, not silently broken. A normal-privilege program cannot see keys typed into an administrator window, so Inkwell says so the first time focus lands in one.

Notes

  • Inkwell keeps no clipboard history, by design.
  • The keystroke buffer is bounded at 64 characters, held in memory only, cleared constantly, and never written anywhere. See the user guide’s Privacy section and the PRD’s security contract.
